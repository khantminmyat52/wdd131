Gamer Hub Site Plan

Khant Min Myat

WDD 131

1. Site Name

Site Name: Gamer Hub

Reason for Name: I chose "Gamer Hub" because it clearly conveys that the website is a central gathering place and resource center for beginner gamers to find essential information.

2. Site Purpose

Purpose: The purpose of Gamer Hub is to provide a beginner-friendly platform offering comprehensive game guides, character overviews, gameplay tips and trending news to help new gamers get started smoothly.

3. Scenarios

  • Scenario 1: "I am new to gaming and want to know which game is best for beginners in 2026."
  • Scenario 2: "How do I understand basic gameplay mechanics and character controls for modern RPGs?"

4. Color Schema

This site plan applies the chosen primary and secondary colors as styled below:

  • Primary Color (#0F172A - Dark Navy): Used for headers, navigation, and primary branding background.
  • Secondary Color (#0EA5E9 - Cyan Blue): Used for accents, buttons, and subheadings.
  • Accent Color (#38BDF8 - Light Blue): Used for link highlights and hover states.

5. Typography

  • Heading Font: 'Trebuchet MS', sans-serif (Used for section titles and main headers)
  • Body Font: 'Arial', sans-serif (Used for paragraphs, list items, and main content text)

6. Wireframes

Mobile Wireframe View: Single-column stacked layout ensuring simple vertical scrolling for mobile users.

Desktop Wireframe View: Multi-column side-by-side grid layout featuring side navigation and responsive content blocks.
